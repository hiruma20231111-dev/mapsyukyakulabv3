# マップ集客ラボ v2 — スタイルガイド（確定 v0.2）

> 担当: `maplab-design-lead` ／ 確定日: 2026-09-10
> ビジュアル版（一望できる指針）: `design/direction.html`（Artifactでも公開）
> 実装の唯一の"見た目の源": `design/tokens.css` / `design/tokens.ts` / `design/icons.tsx`

---

## 0. 一言でいうと
奇抜にしない。v1の「ティール×余白×信頼」を土台に、**Googleの4色を"集客の4つの力"に意味付け**し、**絵文字を自作アイコンに置換**して、"分かりやすさの純度"だけを上げる。presentation のみ・機能は不変。

## 1. 対象ユーザー（毎回思い出す）
お店の店主。**非IT・非マーケ／スマホ中心（幅≤520px）／年齢層高め**。専門用語・小さい文字・低コントラストは届かない。不安を抱えている → 断罪せず、安心と次の一歩を。

## 2. 設計の芯（5原則）
1. **1画面 = 1つの主役**（主ボタン1つ／他は文字リンクへ格下げ）
2. **段階的に見せる**（結論→タップで詳細。診断結果は見出しカードで一望）
3. **アクセシビリティは機能**（本文AA以上／`--fs`倍率で崩れない／色だけに意味を持たせない）
4. **正直なトーン**（煽らない。信頼は余白・整列・一貫性で作る）
5. **速さもUX**（重いライブラリ/画像/アイコンフォントを持ち込まない）

## 3. カラー
- **主役はティール**（`--accent #0e9f8e`）。文字上は `--accent-deep #0b6e63`（白地AA）。
- **注意色は絞る**：`--warn`（琥珀）＝中間評価/残日数、`--danger`（旧pin赤）＝警告のみ。**装飾に使わない**。
- **Googleの4色 = 集客の4つの力の識別色**（下記）。**ボタン・広い面には使わない**（氾濫防止）。

| 力（レバー） | 色 | token |
|---|---|---|
| 見つかる (display) | 🔵 #4285F4 | `--g-blue` |
| 選ばれる (contact) | 🟡 #FBBC05 | `--g-yellow` |
| 来店 (visit) | 🟢 #34A853 | `--g-green` |
| AI検索 (aio) | 🔴 #EA4335 | `--g-red` |

> **重要ルール**：4つの力メーターでは、色＝カテゴリ識別のみ。**強さは「バーの長さ＋強/中/弱ラベル」で示す**（色に二重の意味を持たせない）。4ドットのモチーフはブランド署名／読み込み中インジケータに一滴だけ。

## 4. タイポ（6段スケール）
和文システムフォント前提。太さと余白で階層。`--fs` 倍率は本文系にだけ。
`Display 28/900` · `H1 22/800` · `H2 16/800` · `Body 15/400(×--fs)` · `Small 13/500` · `Micro 11.5/800 大文字`

## 5. 間隔・角丸・影・動き
- Spacing: 4/8/12/16/20/24/32（カード内16・セクション間24）
- Radius: sm10 / md13 / **card16（統一）** / pill
- Elevation: **2段だけ**（e1=カード標準 / e2=ヒーロー・浮遊要素）
- Motion: fast160ms（押下）/ base220ms（出現）/ ease `cubic-bezier(.2,.7,.2,1)`。`prefers-reduced-motion` 尊重。

## 6. アイコン
- **絵文字は使わない**。`design/icons.tsx` の `<Icon name>` を使う。
- 24pxグリッド・線幅1.85・round・単色（currentColor）。色/サイズはトークン・CSSで制御。
- 収録: search / chat / book / pin / gear / pulse / spark / check / slash / star / camera / mega / list / calendar / link（随時追加可・同じ規格を厳守）。

## 7. v1 → v2 の作り替え（6手）
1. Googleの4色を「4つの力」に意味付け
2. 絵文字 → 自作SVGアイコン
3. 1画面1主役（ボタン競合の解消）
4. タイポを6段に固定
5. カード・余白のリズム統一（角丸16・内側16・影2段）
6. 診断結果を"掴める"形に（4つの力メーター＋見出しカード）

## 8. やらないこと
- Googleの4色をボタン・広い面に多用しない
- **機能・診断ロジック・AI憲法・API・localStorageキーに触れない**（presentationのみ）
- 奇抜な配色・派手な装飾・煽り表現
- 重いフォント/画像/アイコンフォント

## 9. 完了の定義（UIレビュー基準）
- [ ] 個別画面に直書きの色/pxが無い（全て `design/` 経由）
- [ ] 絵文字が残っていない（`<Icon>` に統一）
- [ ] `--fs`（小/中/大）でレイアウトが破綻しない
- [ ] 本文コントラスト AA 以上
- [ ] 各画面に主アクションが1つ明確
- [ ] Googleの4色は「4つの力」の識別以外に使われていない
- [ ] 機能・データ挙動を一切変えていない
